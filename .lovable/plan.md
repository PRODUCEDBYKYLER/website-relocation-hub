

# Kyler Chavez — Audio Producer Website

A sleek, dark single-page site for audio producer Kyler Chavez based in Round Rock, TX. Same structure and aesthetic as the David Duque site — moody gradients, smooth scroll, elegant typography — but adapted for a producer selling services and booking sessions.

## Sections

1. **Navbar** — Fixed top nav with "Kyler Chavez" branding, links to sections (Home, Services, About, Contact), and social media icons

2. **Hero** — Full-screen dark gradient background with ambient light orbs, "Kyler Chavez" in large display type, subtitle "Audio Producer · Round Rock, TX", and a prominent "Book a Session" CTA button

3. **Services Section** — Clean card grid showcasing services (e.g. Recording, Mixing, Mastering, Podcast Production — placeholder descriptions for now). Each card with an icon and brief description

4. **About Section** — Two-column layout with photo placeholder and bio text about Kyler as a producer

5. **Contact / Booking Section** — Simple contact form (name, email, service type dropdown, message) with a "Send Inquiry" button. Location mention: Round Rock, TX

6. **Footer** — Social links, copyright, and a "Get in Touch" email CTA

## Design

- Dark color scheme similar to David Duque (warm dark tones, gold/amber accent color)
- Google Fonts: Playfair Display for headings, DM Sans for body
- Smooth scroll between sections
- Subtle fade-in animations on scroll (CSS-only, no framer-motion dependency needed initially)
- Fully responsive / mobile-friendly
